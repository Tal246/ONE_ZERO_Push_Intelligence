# Push Intelligence

מערכת תומכת החלטה לניתוח ביצועי Push Notifications.

## מה כולל הפרויקט?

- `app.py` – קובץ האפליקציה.
- `data/ONE_ZERO_Push_data_80_Rows.xlsx` – קובץ הנתונים לדוגמה.
- `requirements.txt` – הספריות הנדרשות להפעלת הכלי.

## דרישות מקדימות

- Python בגרסה 3.10 ומעלה.
- חיבור לאינטרנט לצורך התקנת הספריות.

## הוראות הפעלה – Mac

1. יש להוריד את תיקיית הפרויקט למחשב ולפתוח אותה.
2. לפתוח Terminal ולעבור לתיקיית הפרויקט:

```bash
cd ~/Desktop/ONE_ZERO_Push_Intelligence
```

3. ליצור סביבת Python:

```bash
python3 -m venv .venv
```

4. להפעיל את הסביבה:

```bash
source .venv/bin/activate
```

5. להתקין את הספריות הנדרשות:

```bash
pip install -r requirements.txt
```

6. להפעיל את האפליקציה:

```bash
streamlit run app.py
```

7. האפליקציה תיפתח בדפדפן בכתובת:

`http://localhost:8501`

## שימוש בכלי

הכלי מאפשר:
- צפייה במדדי ביצועים מרכזיים.
- השוואת וריאציות של קמפיינים.
- זיהוי פערים בין שיעור הקלקה לשיעור השלמת יעד.
- ניתוח מאפייני נוסחי הודעות.
- קבלת כיוונים לניסויים שיווקיים.
- העלאת קובצי נתונים חדשים בפורמט Excel או CSV.

## הערות

הניתוח מבוסס על חישובים וכללים מוגדרים מראש. התובנות הן תיאוריות ואינן מעידות כשלעצמן על קשר סיבתי או על מובהקות סטטיסטית.

לצורך הפעלת הכלי, יש לשמור על מבנה תיקיות הפרויקט ועל מיקום קובץ הנתונים בתיקיית `data`.
